# Drop

> Drop (formerly Massdrop) is a consumer e-commerce brand operated by Corsair, selling limited-edition, community-driven products across mechanical keyboards, audiophile gear, and licensed gaming collaborations. It runs a direct-to-consumer storefront at drop.com. Drop is a retail brand with no public developer API program; this API Evangelist profile tracks it as a company in the network.

## Company
- [Website](https://drop.com): Drop direct-to-consumer storefront and gaming collaborations hub (operated by Corsair).
- [Support Center](https://helpdesk.drop.com/hc/en-us): Zendesk-based customer support and order help.
